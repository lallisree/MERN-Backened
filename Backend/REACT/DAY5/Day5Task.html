2. Difference Between var, let and const

var, let, and const are all used to declare variables in JavaScript,
but they differ mainly in scope, reassignment, and redeclaration.

Feature var let const
Definition var declares a variable that can be

3. Difference Between JavaScript DOM and React

JavaScript DOM is a browser API that allows JavaScript to access and modify HTML elements, while React is a JavaScript library that
helps developers build user interfaces using reusable components and manages UI updates through its rendering system.

Feature JavaScript DOM React
Definition DOM is a browser-provided representation of an HTML document that JavaScript can access and modify. React is a JavaScript library used to build user interfaces using components.
Full Form Document Object Model React is not an abbreviation.
How It Works Directly accesses and changes HTML elements in the DOM. Updates the UI through React's rendering system and then applies necessary changes to the DOM.
UI Structure Usually works directly with HTML elements. Uses reusable components.
Updating UI Developer manually selects and modifies elements. UI updates when component state or props change.
Code Style Uses DOM methods such as getElementById() and querySelector(). Uses JSX, components, props, and state.
Reusability Reusability must be organized manually. Components are designed for reuse.
Example document.getElementById("title") <Title />
Best Suited For Small or simple DOM-based interactions. Large and interactive user interfaces.

5. If you want to build a car, what properties and methods will you use

Let me take a real-life example of a car. A car has some characteristics, such as its brand, color, model, and speed.
In JavaScript, we call these characteristics properties. A car can also perform actions like starting, stopping,
accelerating, and braking. In JavaScript, we call these actions methods. So, properties describe what an object has,
and methods describe what an object does.


Properties

Definition: Properties are the characteristics or information of an object.

For a car, properties can be:

  • brand → Toyota
  • color → Black
  • model → Camry
  • speed → 100
  • fuel → 50

You can say:

“For example, the car has a brand, color, model, speed, and fuel. These are properties because they describe the car.”

Methods

Definition: Methods are the actions or behaviors that an object can perform.

For a car, methods can be:

  • start() → Starts the car
  • stop() → Stops the car
  • accelerate() → Increases speed
  • brake() → Decreases speed
  • honk() → Sounds the horn
